# 预录展示素材入口

最终剪辑视频建议命名为：`p01_showcase.mp4`。剪辑阶段也可直接使用
`p01.mp4`，程序会自动选择它作为备用文件名，不会修改视频内容。

存在 `p01.mp4`、`p02.mp4`……这类编号片段时，预录 NPU 模式会按文件名
顺序连续播放，片段切换时重置时序连续性；退出后不会继续解码视频。

纯前端演示使用 `no_npu/segments/r01.mp4`～`r12.mp4`，并读取同名
`rNN.trace.json`。trace 由完整视频在板端正常 NPU 链预跑一次后自动记录，
再按媒体时间机械切分；视觉字段不得人工填写。手机类别允许按采集说明在
pre-log 期间人工定时注入。页面可手动进入纯前端模式，预录 NPU 失败时
也会自动进入该模式，并明确显示 `NPU BYPASSED`。纯前端模式同样按
`r01`～`r12` 连续播放，片尾自动切换同名视频和预日志，不循环单个片段。

读取优先级为：环境变量 `EDGEFOCUS_DEMO_VIDEO` →
`assets/demo/p01_showcase.mp4` → `assets/demo/p01.mp4`。

建议编码：H.264 / yuv420p / 640×480 / 25 或 30 FPS / 无音轨。
视频时长可在 30～35 秒之间。前端保底轨迹文件为
`p01_showcase.trace.json`，待成片冻结后按最终时间轴生成。
