## 推荐挑选方式

- 版面只能放 2 张：选 A1 + A2。
- 能放 4 张：选 A1 + A2 + A3 + A4。
- 增加工程说明区：从 B5 云台、B6 风扇、B8 Demo 隔离、B9 部署中选 2–4 张。
- 强调边缘 AI 赛道：使用 C04 + C06 + C08，并在旁边放 `58-D × 16 steps`、`4 个计算域`、`100 ms` 三个指标。
- 强调完整产品：使用 C0 + C03 + C05 + C11。

## 固定视觉语义

| 颜色 | 含义 |
|---|---|
| 蓝色 `#1677FF` | 用户、App、浏览器、手环 |
| 深青 `#08979C` | A35/Linux 业务、会话、存储、策略 |
| 紫色 `#7C3AED` | AI/NPU、时序模型、Fusion |
| 橙色 `#F97316` | M33、G431 等实时协处理器 |
| 绿色 `#16A34A` | 摄像头、风扇、云台、供电等物理设备 |
| 红色 `#DC2626` | Fault、安全停机、降级 |
| 灰色 `#6B7280` | Demo-only、诊断、兼容投影 |

箭头规则：实线表示业务数据，粗线表示控制/执行，双向表示协议与状态交换，虚线表示诊断或 Demo-only，红线表示故障与安全回退。

## 不应出现的旧概念

- 困倦、闭眼疲劳或“建议休息”；
- 视觉层直接判断“正在使用手机”；
- 板载屏幕、板载声音提醒；
- 电池电量百分比；
- 云台“待完成、待接入、未验证”；
- 把指定型号的 TOPS 当作项目创新指标或实测端到端吞吐。

## Mermaid 导出建议

Mermaid 是结构源，不必直接作为最终海报美术稿。导出 SVG 后可在 Figma、Illustrator、draw.io 或 PPT 中重排，但需保留节点名称、箭头方向、颜色语义与量化口径。
