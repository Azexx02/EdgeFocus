# STM32G431 云台副板程序说明

## 1. 程序用途

本工程运行于 STM32G431RBT6，负责：

- 两路 AS5600 绝对角度读取；
- X/Y 两轴三相 PWM 电机驱动；
- 低速绝对定位、双轴轨迹和回中；
- 电压模式 FOC 位置保持；
- X 轴机械限位与堵转保护；
- Boost、DAC、电流 ADC 和驱动故障管理；
- 通过 UART4 接受 STM32MP257 或上位机控制。

当前产品约束为：X 轴机械范围 `0..180°`，Y 轴为 `0..359°` 连续轴。

## 2. 逻辑轴与硬件映射

映射以 `motor_pwm.c:get_axis_hardware()` 为唯一代码依据。

| 逻辑轴 | 编码器 | 电机 PWM | EN / STBY | DAC 电流参考 | ADC 电流采样 |
|---|---|---|---|---|---|
| X | I2C1：PA15/PB7 | TIM1：PA8/PA9/PA10、PB13/PB14/PB15 | PA6 / PC0 | PA5 / DAC1_OUT2 | PA2 / ADC1_IN3 |
| Y | 软件 I2C：PB10/PB11 | TIM8：PC6/PC7/PC8、PA7/PB0/PB1 | PA0 / PC1 | PA4 / DAC1_OUT1 | PA1 / ADC1_IN2 |

注意：CubeMX 信号名中存在早期 X/Y 命名遗留，业务逻辑必须使用 `GIMBAL_AXIS_X/Y`，不得根据 GPIO 宏名称推断轴。

## 3. 主要硬件参数

| 项目 | 参数 |
|---|---|
| MCU 时钟 | 170 MHz |
| UART4 | 115200，8N1，无流控 |
| AS5600 | 12 bit，原始范围 `0..4095` |
| I2C1 | X 轴编码器硬件 I2C |
| 软件 I2C | Y 轴编码器，PB10/PB11，约 50 kHz |
| TIM1/TIM8 | 中心对齐 PWM，ARR=4249，约 20 kHz |
| 电机极对数 | 7 |
| FOC 位置环周期 | 10 ms |
| FOC 输出看门狗 | 100 ms |

软件 I2C 使用 DWT 微秒延时，同时带循环次数兜底，DWT 异常时不得无限卡住主循环。

## 4. 软件模块

| 文件 | 作用 |
|---|---|
| `app_gimbal.c` | 初始化与主循环调度 |
| `board_config.c` | Boost、DAC、故障输出和板级安全状态 |
| `as5600.c` | 两路 AS5600 读取 |
| `soft_i2c.c` | Y 轴编码器软件 I2C、超时与总线恢复 |
| `motor_pwm.c` | 轴映射、定位、FOC、限位和堵转保护 |
| `current_sample.c` | 两路总电流 ADC 采样 |
| `gimbal_storage.c` | 标定数据 Flash 保存和加载 |
| `uart_protocol.c` | UART4 命令、响应、急停和错误恢复 |

`main.c` 完成 CubeMX/HAL 外设初始化后，只调用 `app_gimbal_init()` 和 `app_gimbal_process()`。

## 5. 上电安全状态

上电和复位后：

- 两轴 EN/STBY 拉低；
- Boost 关闭；
- PWM 比较值清零；
- 两路 DAC 恢复 300 mV；
- FOC 和保持关闭；
- 从 Flash 加载有效标定；
- Y 连续轴建立当前单圈坐标。

上电约 800 ms 后自动执行一次 X 轴开机寻限位。完成低功率电角度对齐后，X 轴以编码器位置闭环 FOC 寻找两侧机械端点；若开机位置已经靠近第一端点，则自动改为从另一方向开始扫描。两个端点之间的 AS5600 原始计数按比例映射到逻辑 `0..180°`，随后回到逻辑中心 90°。Y 轴不参与。UART 输出 `BOOT_HOME,X_START` 和 `BOOT_HOME,X_OK`，失败时输出 `ERR,BOOT_HOME_X`。

自动标定不再假设“AS5600 原始 180°等于云台机械 180°”。端点原始距离只用于建立比例尺，逻辑角度换算统一采用：

```text
logical_deg = raw_offset / endpoint_raw_span * logical_travel_deg
```

端点距离过小、回中失败或编码器读取失败时，标定无效，`STAT` 返回 `XHOME=0,CAL=0`，所有 X/XY/HOLD 运动命令都会被拒绝。

普通定位、自动寻限位、自动回中、位置保持和电机转动测试统一使用位置闭环 FOC，不再提供开环六步换相运动入口。

只有 `STAT` 返回 `SAFE=0,XHOME=1,YHOME=1,CAL=1` 时，主程序才允许发送运动命令。

## 6. 点到点位置控制

业务命令：

```text
SET XY <x_deg> <y_deg>
MOVE XY <x_deg> <y_deg> <speed>
DEG X <0..180>
DEG Y <0..359>
CENTER X
```

X 轴由协议层自动拆成最大 5°的内部闭环段，主程序只发送最终目标。Y 轴跨越 0°时按最短角差运动。

每段定位会识别换相方向、读取编码器并检查轨迹窗口。到位或失败后关闭该次定位输出。错误后必须执行 `STOP`，不得自动重发运动命令。

## 7. FOC 位置保持

使用方法：

```text
SET XY 90 0
HOLD 1
```

`HOLD 1` 会读取当前两轴绝对角度并保存为本次 RAM 保持点，响应中返回 `X=<captured_x>,Y=<captured_y>`。外力位移后控制器始终以该保存点为回归目标。复位后的首次启用先执行专用电角度零点和方向对齐，点到点运动不再覆盖该零点；对齐造成的短暂位移随后由位置环拉回保存点。

关闭：

```text
HOLD 0
```

当前硬件没有三相相电流采样，因此实现的是：

1. AS5600 机械角读取；
2. 专用对齐流程确定编码器方向和电角度零点；
3. 机械角乘 7 极对并减去零点得到电角度；
4. 位置误差与误差微分组成 PD 控制量，生成 q 轴方向和电压幅值；
5. TIM1/TIM8 持续输出三相正弦电压矢量；
6. 误差死区内使用较低磁场保持；
7. 偏差增大时逐步提高保持力矩。

这属于编码器位置环加电角度的电压模式 FOC，不是带三相电流 PI 环的电流模式 FOC。

电角度与 q 轴实现参考“双电机驱动 HAL FOC”工程的 `zero_electric_angle`、Park/Clark 逆变换和 5 ms 周期任务思路，并针对本板调整为整数正弦查表、10 ms 双轴调度和互补 PWM。实板桥臂相序要求 X/Y 使用独立 q 轴符号；位置环加入误差微分阻尼，防止 Y 轴在高恢复力矩下越过目标持续振荡。

保持安全机制：

- 主循环每 10 ms 刷新控制和看门狗；
- SysTick 独立监控 100 ms 心跳；
- 心跳丢失时直接关闭 PWM、EN/STBY 和 Boost；
- 位置持续大幅偏离时关闭保持并记录故障；
- `HOLD 0`、`STOP` 或单字节 `!` 均可关闭保持；
- `!` 不需要换行，并全局优先处理。

运行诊断命令 `FOCSTAT` 可读取两轴电角度就绪状态、位置误差、当前输出幅值、循环计数、看门狗触发次数和 UART 错误恢复次数。

当前保持参数：X 轴正弦幅值 `260..1200 ticks`、DAC 1500 mV；Y 轴 `220..900 ticks`、DAC 1600 mV。控制器带力矩迟滞、误差微分阻尼、启动软升幅和每周期占空比斜率限制，用于减少目标附近反复换向和 `HOLD 1` 突然抖动。偏差持续过大时约 300 ms 内关闭保持。长时间运行仍必须复核温升。

## 8. 限位与堵转保护

X 轴闭环运动期间，编码器连续约 280 ms 几乎没有位移时立即关闭输出：

| 错误码 | 提示 | 含义 |
|---:|---|---|
| 12 | `LIMIT=X_MIN` | 到达 X 最小机械端 |
| 13 | `LIMIT=X_MAX` | 到达 X 最大机械端 |
| 14 | `LIMIT=X_BLOCKED` | X 中途堵转或被阻挡 |

Y 轴为连续轴，不做机械端点判定。

## 9. UART 可靠性

命令必须以 `\r\n` 或 `\n` 结束。持续 PWM 会增加电磁干扰，UART 接收层会自动清除 ORE、FE、NE 错误并恢复接收。

单条命令最多 63 字节。超长命令只返回一次 `ERR,LINE_TOO_LONG`，随后丢弃到本行结束，不会把剩余字符误解析成第二条命令。

主程序规则：

- 查询命令超时或收到损坏响应时可重试 1 次；
- 运动命令不得自动重试；
- 急停时可连续发送 3 个 `!`；
- UART4、编码器和电机线应分开走线；
- UART TX/RX 建议与 GND 绞合，必要时增加串联阻尼和屏蔽。

## 10. 电流与热安全

板上只有两轴总电流 ADC，没有 U/V/W 三相电流采样。当前 `GIMBAL_CURRENT_LIMIT_RAW=4095`，软件 ADC 跳闸等效关闭，主要依赖 STSPIN830 故障输出、DAC 参考限制、位置偏差保护和 FOC 看门狗。

长时间保持前必须实测电机、驱动和线束温升。若要实现真正电流模式 FOC，需要增加可靠的三相或至少双相电流采样，并同步到 PWM 中点采样。

## 11. 构建与烧录

构建：

```powershell
cmake --build build\Debug
```

输出：

```text
build\Debug\STM32_Project.elf
```

当前 SWD 链路偶发随机地址校验失败。烧录必须启用 verify，并且只有出现以下信息才允许运行电机：

```text
Download verified successfully
```

建议使用 50 kHz SWD、缩短 SWDIO/SWCLK/GND/NRST 线并确保可靠共地。

## 13. 当前实机验收结果

已通过 COM28（115200，8N1）验证：

- `VER`、`PING`、`HELP`、`ECHO`；
- `STAT`、`ANGLE`、`FAULT`、`FOCSTAT`、`HOMEINFO`；
- `AUTOHOME X`、`CALSAVE`、`CALLOAD`；
- `DEG X`、`DEG Y`、`SET XY`、`MOVE XY`；
- 越界参数、未知命令、LF/CRLF、超长帧和单字节急停。

最终安全状态应为 `BOOST=0,MOTOR=0,HOLD=0`。
