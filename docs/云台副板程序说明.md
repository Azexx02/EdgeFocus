# STM32G431 云台副板程序说明

## 1. 程序用途

本工程运行于 STM32G431RBT6，用于完成两轴云台的编码器读取、电机驱动、电流采样、Boost 控制和与 STM32MP257 的 UART4 通信。

当前版本用于硬件联调和低速位置控制。电机控制采用低占空比六步换相，不是最终高速 FOC 算法。

## 2. 最终云台轴定义

程序中的 X/Y 均表示云台逻辑轴，硬件关系直接按 MCU 引脚定义。

| 逻辑轴 | 编码器 | 电机 PWM | 使能/待机 | 电流参考 | 电流采样 |
|---|---|---|---|---|---|
| X 轴 | I2C1：PA15(SCL)、PB7(SDA) | TIM8：PC6/PC7/PC8、PA7/PB0/PB1 | PA0 / PC1 | PA5 / DAC1_OUT2 | PA2 / ADC1_IN3 |
| Y 轴 | 软件 I2C：PB10(SCL)、PB11(SDA) | TIM1：PA8/PA9/PA10、PB13/PB14/PB15 | PA6 / PC0 | PA4 / DAC1_OUT1 | PA1 / ADC1_IN2 |

轴与 MCU 外设的映射统一维护在 `motor_pwm.c` 的 `get_axis_hardware()` 中。

## 3. 主要硬件参数

- 系统时钟：170 MHz。
- UART4：115200、8N1、无流控。
- I2C1：100 kHz，AS5600 地址 0x36。
- 软件 I2C：PB10/PB11，约 50 kHz，要求外部上拉至 3.3 V。
- TIM1/TIM8：中心对齐 PWM，ARR=4249，约 20 kHz，死区 85 ticks。
- DAC 初始参考电压：300 mV。
- AS5600 原始角度范围：0~4095，读取失败返回 65535。

## 4. 软件模块

| 文件 | 作用 |
|---|---|
| `app_gimbal.c` | 应用初始化和主循环调度 |
| `board_config.c` | Boost、DAC、故障输出和板级安全状态 |
| `as5600.c` | 两路 AS5600 读取及逻辑轴定义 |
| `soft_i2c.c` | PB10/PB11 软件 I2C、超时和总线恢复 |
| `motor_pwm.c` | 逻辑轴映射、六步换相、驱动故障检测和低速定位 |
| `current_sample.c` | 两路 ADC 电流采样及逻辑轴映射 |
| `uart_protocol.c` | UART4 行命令接收、解析和响应 |

`main.c` 只负责 HAL/CubeMX 外设初始化，然后调用 `app_gimbal_init()` 和 `app_gimbal_process()`。

## 5. 上电安全状态

程序上电后执行以下动作：

- EN 和 STBY 全部拉低。
- Boost 关闭。
- PWM 比较值清零。
- 故障输出清零。
- 两路 DAC 设置为 300 mV。
- ADC 完成单端校准。

STSPIN830 的 EN/FAULT 是复用开漏信号。GPIO 配置为开漏：拉低表示关闭驱动，释放后由外部电阻上拉；如果驱动器再次将其拉低，程序判定为驱动故障并停止换相。

## 6. UART4 调试协议

命令以 CRLF 或 LF 结尾。

| 命令 | 说明 | 示例响应 |
|---|---|---|
| `PING` | 通信测试 | `OK,G431` |
| `ANGLE` | 读取逻辑 X/Y 编码器 | `STAT,X=1234,Y=2850,EN=0` |
| `BOOST 1` | 开启 12 V Boost | `OK,BOOST_ON` |
| `BOOST 0` | 关闭 Boost | `OK,BOOST_OFF` |
| `MOTOR 1` | 释放两路驱动使能，PWM 保持为零 | `OK,MOTOR_ON` |
| `MOTOR 0` | 关闭两路驱动 | `OK,MOTOR_OFF` |
| `TEST X` | 测试逻辑 X 轴（TIM8） | `TEST,X_START` / `TEST,X_END` |
| `TEST Y` | 测试逻辑 Y 轴（TIM1） | `TEST,Y_START` / `TEST,Y_END` |
| `POS X n` | X 轴定位至 n，n=0~4095 | `POS,X=...` |
| `POS Y n` | Y 轴定位至 n，n=0~4095 | `POS,Y=...` |

测试或定位期间检测到 EN/FAULT 拉低时，返回 `ERR,X_FAULT`、`ERR,Y_FAULT` 或位置控制错误，并关闭该轴输出。

## 7. 低速位置控制说明

`POS X n` 和 `POS Y n` 使用以下流程：

1. 根据逻辑轴选择对应电机、编码器、EN/STBY 和定时器。
2. 低功率执行一个电角周期，自动判断相序正方向对应编码器增大还是减小。
3. 按 12 位环形角度的最短方向逐步换相。
4. 每次读取编码器前短暂关闭 PWM，降低功率开关对 I2C 的干扰。
5. 误差连续三次进入 ±12 counts 后判定到位。
6. 到位、超时、编码器失败或驱动故障后关闭输出。

该控制适合板级验证和低速点到点定位。到位后不会持续保持力矩。正式云台控制应继续开发：电角度标定、极对数配置、FOC、电流环、速度环、位置环和故障状态机。

## 8. 构建方法

在工程根目录执行：

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

输出固件：

```text
build/Debug/STM32_Project.elf
```

建议每次修改 CubeMX 配置后执行一次全量构建：

```powershell
cmake --build --preset Debug --clean-first
```

## 9. 下载和联调建议

1. 首次接电机时将电源限流设为 0.2~0.5 A。
2. 先执行 `PING`、`ANGLE` 和 `BOOST 0`。
3. 确认编码器随轴转动且数值在 0~4095 内变化。
4. 使用 `TEST X` 或 `TEST Y` 分别验证对应逻辑轴。
5. 观察 EN/FAULT、12_SYS 和六路 PWM。
6. 异常时立即执行 `MOTOR 0`、`BOOST 0` 或直接断电。

## 10. 已确认的硬件联调事项

- PB10/PB11 软件 I2C 已实板验证；早期无应答由接口虚焊导致。
- 某一相 PWM 引脚焊接异常时，电机可能完全不转或出现缺相抖动，可直接在对应 MCU 引脚测量波形。
- EN/FAULT 必须使用开漏 GPIO，不能配置成普通推挽高电平。
- AS5600 在电机 PWM 工作时可能受到干扰，位置控制使用静默采样和重试机制。
