## 必读顺序

1. `EdgeFocus-最终最终版主链路文档.md`
   - 当前产品和工程主口径。
   - 用于理解主机、App、手环职责和可演示主链路。

2. `EdgeFocus-最终工作流程与交互时机.md`
   - 主链路时序口径。
   - 用于明确 start、skip、phone_sync、行为判断、提醒、手环写入、结束、报告、历史、反馈分别在什么时候发生。

3. `EdgeFocus-最终云台架构与备忘录Todo收口.md`
   - 云台/预检的当前边界、未来真实云台模块边界、旧备忘录 Todo 的完成/后置/废弃状态。
   - 用于避免把云台真实驱动、校准失败原因、UI 中文化细节错误排到主链路前面。

4. `EdgeFocus-最终最终校对文档.md`
   - 旧口径纠偏清单。
   - 用于避免再次误写 PHONE_IN_PLAYING 固定 LEVEL_3、silent 降级、App 直连手环等错误。

5. `EdgeFocus-最终API契约-App主机.md`
   - App 与主机 BLE GATT、JSON 命令、响应、push、字段、枚举的最终契约。
   - 后续 App/主机联调优先以本文为字段级依据。

6. `EdgeFocus-最终API契约-主机手环.md`
   - 主机与手环 BLE GATT、Alert/TimeSync/Text 帧、诊断字段和测试口径的最终契约。
   - 手环已送封装，默认不主动改固件。

7. `P0-协议冻结清单.md`
   - 跨端协议冻结依据。
   - App-主机 FF00/FF01/FF02、12 个普通命令、4 个 push、主机-手环 0x180C/0x2A56 均以此为准。

8. `P0-接口变更流程.md`
   - 如果未来必须改协议字段或 BLE 帧，先走这个流程。

## API 原始资料

`api文档/` 目录保留为旧 API 原始资料池，包含上个月或更早的契约、补充说明和旧需求稿。该目录不直接作为权威入口。

后续判断字段时按以下优先级：

1. 当前代码实际行为。
2. `EdgeFocus-最终API契约-App主机.md` 与 `EdgeFocus-最终API契约-主机手环.md`。
3. `P0-协议冻结清单.md`。
4. `api文档/` 旧资料，仅用于追溯来源和发现遗漏。

## 旧文档与旧 Todo

旧总纲、旧推进计划、旧 Todo、早期 App/手环总结和 `doc/` 目录的原文已不再作为权威入口，因为其中部分内容已被最终文档覆盖或可能误导后续会话。

旧备忘录/Todo 中仍有价值的事项已经归档到 `EdgeFocus-最终云台架构与备忘录Todo收口.md`，按已完成、当前主链路、后置、废弃口径处理。

## 当前关键口径

- 主机是权威数据源。
- App 只连接主机，不直连手环。
- 手环只作为提醒终端，当前无 ACK、Notify、状态读取、电量上报。
- `PHONE_IN_USE` / `PHONE_IN_PLAYING` 是行为输入，不固定映射提醒等级。
- silent/normal 只筛选提醒渠道，不改变严重程度。
- 当前优先推进主机可独立完成核心功能：启动会话 -> 手动 skip 云台/预检 -> 视觉/手机输入 -> 行为层 -> 提醒 -> 结束 -> 报告/历史/反馈。
- 不优先推进云台驱动、校准协议修改、Dashboard 重构、手环上行能力。
