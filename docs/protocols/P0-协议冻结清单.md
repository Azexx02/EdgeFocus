## 4.1 手机状态与提醒等级声明

`PHONE_IN_USE`、`PHONE_IN_LEARNING`、`PHONE_IN_PLAYING` 是行为层状态/输入，不是最终提醒等级。

冻结规则：

- `PHONE_IN_USE` 不固定对应 `LEVEL_2`。
- `PHONE_IN_PLAYING` 不固定对应 `LEVEL_3`。
- `phone_sync.distraction_level` 是手机侧使用情况输入，不是板端最终 `CommandLevel`。
- 最终是否提醒、提醒等级是多少，必须由主机行为层和 `ReminderPolicy` 综合判断。
- 手环只接收主机最终 Alert 帧 `{0x01, vibration_pattern, level}`，不接收手机使用状态。

## 6. 主机 ↔ 手环 BLE

| 项目 | 冻结值 |
|---|---|
| 主机角色 | BLE Central |
| 手环角色 | BLE Peripheral |
| 手环广播名 | `EdgefocusBand` |
| Service UUID | `0x180C` / `0000180c-0000-1000-8000-00805f9b34fb` |
| Write Characteristic | `0x2A56` / `00002a56-0000-1000-8000-00805f9b34fb` |
| 当前方向 | 主机写入手环 |
| 当前主链路 | 主机 C++ BlueZ D-Bus `GattCharacteristic1.WriteValue` |
| 当前无上行 | 无业务 ACK、无 Notify、无状态读取、无手环电量上报 |

## 7. 手环二进制帧

### Alert

```text
Byte0 = 0x01
Byte1 = vibration_pattern
Byte2 = level
```

当前主机运行时只发送 Alert。

### TimeSync

```text
Byte0 = 0x02
Byte1 = minutes_hi
Byte2 = minutes_lo
```

手环固件支持，主机当前未接入主流程。

### Text

```text
Byte0 = 0x03
Byte1-N = ASCII text bytes
```

手环固件支持，主机当前未接入主流程；不承诺 UTF-8 中文。
