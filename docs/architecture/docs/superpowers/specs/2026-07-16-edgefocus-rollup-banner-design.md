# EdgeFocus 80 × 200 cm 比赛易拉宝设计规格

## 1. 目标与交付范围

制作一张用于比赛现场展示的 `80 × 200 cm` 竖版 EdgeFocus 易拉宝。成稿以中文为主，保留必要英文技术术语；不放学校/团队 Logo、比赛 Logo 或二维码。

视觉方向采用已批准的 C 方案“工程蓝图风”：浅灰蓝网格背景、深青主标题、紫/蓝/橙三类技术强调色、浅色信息区。版面强调真实产品、端侧 AI、多源 Fusion 与异构安全，不复刻完整工程文档。

正式交付物：

- `edgefocus-rollup-80x200.ai`：Illustrator 2025 可编辑源文件，CMYK，嵌入必要素材。
- `edgefocus-rollup-80x200-print.pdf`：印刷 PDF，目标为 PDF/X-4，保留矢量文字与线条。
- `edgefocus-rollup-80x200-preview.png`：RGB 长图预览，建议 `1600 × 4000 px`。
- `edgefocus-rollup-assets/`：进入成稿的三张融合架构 SVG、海报专用 `.mmd` 及必要中间素材副本。

不修改或覆盖工作区中的原始 JPG/PNG、Markdown 与 `.mmd` 文件。

## 2. 画布与印刷边界

- 成品裁切尺寸：`800 × 2000 mm`。
- 暂定出血：四周 `3 mm`；印刷厂要求不同时以印刷厂模板为准。
- 左右内容安全边距：至少 `18–20 mm`。
- 顶部安全边距：至少 `20 mm`。
- 底部保留 `80 mm` 的低优先级安全区，避免卷轴底座或安装误差遮挡重要信息。
- 重要标题、节点、指标不得进入出血或底部安全区。
- Illustrator 文档使用 CMYK；Raster Effects 设为 `150 ppi` 或更高。

### 3.1 FIG.01 端侧系统闭环与可靠交互

融合来源：

- `poster-mmd/02-session-lifecycle-strip.mmd`
- `poster-mmd/04-app-reliable-interaction.mmd` 中的可靠协议要点

内容边界：

- 上行信息：会话命令、PRECHECK 控制、PhoneFact。
- 下行信息：权威状态、Alert、最终报告。
- 可靠交互短链：`hello/get_state → command_id/event_id → ACK → Outbox/重连恢复`。
- 会话状态带：`IDLE → PRECHECK → FOCUSING ↔ PAUSED → ENDING`，作为 FIG.01 下方的一条独立窄带。

目标：评委在数秒内理解“用户如何使用产品、事实如何进入主机、提醒如何可靠返回”。

### 3.2 FIG.02 Edge AI + Temporal Fusion

融合来源：

- `poster-mmd/03-edge-ai-fusion.mmd`
- 原 App 图中的 PhoneFact 心跳与 TTL 事实

生成海报专用的同拓扑紧排版本。完整保留现有 Mermaid 的节点、连线、分支、嵌套子图和层级关系，不将其简化为扁平证据链。必须保留：

- `YOLO11n Pose / 17 keypoints`
- `58-d × 16 steps / 2 s temporal window`
- `Presence + Temporal Prone`
- PhoneFact 四分类：`OFF / LEARNING / ENTERTAINMENT / OTHER`（未使用 / 学习 / 娱乐 / 其他）
- `2 s heartbeat / 5 s freshness TTL`
- `FusionCore + Episode`
- `NOT_PRESENT / UNKNOWN` 不产生分神提醒
- `Level 0` 正常与 `Level 1–3` 三级分神
- 现有视觉感知、主体与时序、PhoneFact、Fusion、Episode、Assessment、输出等级和 guards 等分组及嵌套层级

实现时新建海报专用 Mermaid 源文件，不覆盖现有 `poster-mmd/03-edge-ai-fusion.mmd`。建议文件名为 `edgefocus-rollup-assets/02-edge-ai-fusion-tight.mmd`。新图必须保持现有 Mermaid 视觉语言：AI 紫、Host 青、External 蓝、Fault 红、Device 绿，继续使用相同的布局方向、矩形节点、线宽、箭头和中英混排方式。仅通过 Mermaid 的 `nodeSpacing`、`rankSpacing`、`diagramPadding` 和文本换行减少空白，不删除节点、不合并节点、不减少嵌套层级，也不改变语义拓扑。导出 SVG 后再按真实图形边界裁切画板，进一步去除外围无效留白。

### 3.3 FIG.03 异构计算与安全闭环

融合来源：

- `poster-mmd/05-heterogeneous-safety.mmd`
- 透明拆解图 `已有素材/微信图片_20260716103247_12373_23.png`

必须保留：

- A35/Linux：会话、Fusion、BLE、存储与安全编排。
- NPU：YOLO11n Pose。
- Cortex-M33：`100 ms` 风扇闭环，A35 失联 `3 s` 后安全高转。
- STM32G431：云台实时控制、本地 Fault 停机。
- `RPMsg`、`UART4 115200`、`PD7 Enable`、`PD6 Fault`。
- External Power 的 `3 × 250 ms` 去抖；Home/Go 只改变业务节拍，安全环不降频。

透明拆解图放在本区左侧或作为局部实物标注，不遮挡 SVG 节点。该图回答“为什么是四个计算域，以及单点异常为什么不会扩大为全系统停机”。

## 8. Illustrator 与素材处理

- 使用 Adobe Illustrator 2025 作为主排版工具。
- 三张主架构图从 `.mmd` 重新输出为 SVG；FIG.02 使用新生成的同拓扑紧排 `.mmd`，保持完整节点与嵌套层级。所有 SVG 按实际图形边界裁切，避免原 SVG 画板产生无效空白。
- SVG 进入 Illustrator 后嵌入或展开为可编辑矢量组；保持文字、箭头和节点为矢量。
- SVG 的比例、容器高度与遮挡在 Illustrator 阶段以实际内容边界校正；不得拉伸 SVG，也不得让 Figure 标题、设备抠图或相邻区块覆盖节点和连线标签。
- 两张透明 PNG 使用现有 alpha 通道；只做缩放、位置、轻微色彩统一和非破坏性阴影，不重新抠图。
- JPG/PNG 必须嵌入最终 `.ai`，防止移动文件后丢链。
- 所有原始素材保留不变，调整只发生在工作副本或 Illustrator 文档中。

## 9. 可读性与错误处理

- 若三张 SVG 在目标宽度下仍有节点小于 `20 pt`，优先收紧 Mermaid 间距和优化换行；可在 Illustrator 外部版面中调整容器高度，并在不侵占底部 `80 mm` 安全区的前提下重新分配区块高度。FIG.02 不改变 Mermaid 布局方向；不得删除节点、合并语义节点或减少嵌套层级，也不通过继续缩小字号解决。
- 若架构图与容器比例不匹配，改变容器高度或重新排图；不保留大面积无意义空白。
- 若透明 PNG 边缘出现黑边/白边，在 Illustrator 中使用剪切路径或在工作副本中清理，不覆盖原文件。
- 若某个素材低于目标有效分辨率，限制其印刷尺寸；不进行虚假细节锐化。
- 若 PDF/X-4 预设不可用，输出保留 CMYK、字体嵌入、出血和矢量内容的高质量 PDF，并记录所用预设。

## 10. QA 与验收标准

1. 打开 `.ai` 时无缺失链接、缺失字体或替代字体警告。
2. PDF TrimBox 为 `800 × 2000 mm`，BleedBox 暂定为四周各 `3 mm`。
3. 三张架构图和状态带均完整，没有裁切节点、重叠文字或穿过标签的连线。
4. 在 Illustrator 100% 视图和缩小全页预览下，标题层级清楚，底部 PCB 栏完整可见。
5. 按实际宽度估算，核心架构节点不小于 `20–22 pt`。
6. 成品与拆解 PNG 透明背景正确，没有室内背景矩形或明显抠图边缘。
7. 关键事实与 `edgefocus-complete-architecture.md`、App 架构和五张原始 `.mmd` 一致。
8. 输出 PDF 使用 CMYK，黑色文字与细线不过度套印，浅色网格不会干扰节点阅读。
9. 预览 PNG 为 `1600 × 4000 px` 或等比例更高分辨率，完整显示 PCB 区和底部安全区。
10. App 五界面拼贴的图片均未拉伸；顶部横屏为主视觉，后两张横屏不抢占主架构图注意力。
