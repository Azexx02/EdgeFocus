# EdgeFocus 硬件亮点文本区规格

日期：2026-07-16

## 范围

以用户最新保存的 `edgefocus-rollup-80x200.ai` 为母版，只在 HARDWARE ARCHITECTURE 左侧 PCB 下方空白区添加可编辑文本，不移动、缩放或重建其他对象。按用户要求跳过独立审查。

## 文本与字数

- 标题：`硬件设计亮点`
- 正文共 145 个字符（不计空格与换行）；包含标题共 151 个字符。
- 正文使用用户提供的三条内容，去掉冒号后的多余半角空格，语义和标点不改。

## 排版

- 可用区约 `x=35..294 mm`、`y=688..778 mm`。
- 标题：Microsoft YaHei Bold，23 pt，深蓝色；左侧增加 2.5 mm 宽橙色短竖线。
- 正文：Microsoft YaHei，17 pt，约 21 pt 行距，深灰色。
- 每条为独立可编辑区域文本框；编号与小标题使用粗体深蓝色，说明文字使用常规深灰色。
- 三条依次放置，不与 PCB、右侧硬件图、硬件卡片底边或 FIG.02 顶边重叠。

## 验收

- 三条文本完整显示，无溢出、乱码、孤行或截断。
- 最低文字底边位于硬件卡片底边之上至少 8 mm。
- AI 保持 800 × 2000 mm、CMYK、6 图层、无外链。
- 重新导出 AI、印刷 PDF 和 PNG 预览。
