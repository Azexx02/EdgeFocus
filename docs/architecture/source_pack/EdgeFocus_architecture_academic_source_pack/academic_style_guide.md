# Academic figure style guide

| Semantic role | Stroke | Light fill |
|---|---:|---:|
| External / communication | `#2F5597` | `#F1F4F8` |
| Host / fusion | `#2F6F73` | `#F0F6F5` |
| AI / NPU | `#6C5A8D` | `#F5F2F7` |
| Real-time / safety | `#A96320` | `#FAF4EC` |
| Device / actuator | `#557A46` | `#F2F6EF` |
| Critical outcome | `#A63D40` | `#FAF0F0` |
| General connector | `#46505A` | - |
| Logical boundary | `#9AA3AD` | `#FCFCFC` |

Recommended export: SVG for publication; 1920 x 1080 PNG for slides and posters.
