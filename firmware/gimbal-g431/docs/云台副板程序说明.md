# STM32G431 云台副板固件说明

## 1. 固件定位

固件驱动两路 STSPIN830 和两路 AS5600，实现 P/Y 两轴 FOC 位置控制、连续旋转、位置保持、视觉跟踪和圆轨迹。当前配置默认启用纯串口模式，一体板无需连接 Enable、Fault、BOOT0 或 NRST 即可正常控制。

## 2. 关键约定

- P = Pitch（俯仰），Y = Yaw（航向），对外协议不使用 X/XY。
- 两轴按 `0..359°` 环形坐标运行，没有软件机械限位。
- `ARM` 执行电角度、方向和极对数对齐；当时姿态作为本次启动参考。
- 所有定位命令进入非阻塞 FOC 位置环，不使用撞限位寻零或阻塞式移动。
- P 轴采用更柔和的斜坡、阻尼和自适应重力补偿；Y 轴优先响应速度。

## 3. 代码模块

| 文件 | 职责 |
|---|---|
| `app_gimbal.c` | 初始化、ARM/停止状态和主循环调度 |
| `motor_pwm.c` | 双轴 FOC、位置环、目标斜坡和 P 轴重力补偿 |
| `uart_protocol.c` | UART 缓冲、协议解析和轨迹生成 |
| `as5600.c` | 双编码器读取 |
| `board_config.c` | Boost、驱动使能、DAC 和板级故障输出 |
| `current_sample.c` | 电流 ADC 采样 |

FOC 控制周期为 5 ms。UART 使用中断缓冲，运动期间仍能处理查询和停止命令。

## 4. 启动验收

```text
PING
VER
STAT
ANGLE
ARM
PITCH 10
YAW 10
ANGLE
FOCSTAT
STOP
STAT
```

验收重点：

- `ARM` 返回 `BOOT_ALIGN,START`、`BOOT_ALIGN,OK`、`OK,ARM`。
- PITCH 只改变 P 轴，YAW 只改变 Y 轴。
- `P_RAW/Y_RAW` 不能为无效值，手动转动对应轴时应变化。
- 到位后 `PE/YE` 逐步减小，`PDUTY/YDUTY` 不应长期满输出。
- `STOP` 后 `BOOST=0,MOTOR=0,HOLD=0`。

## 5. 维护注意事项

- 更换负载或改变安装方向后发送 `GRAVCLEAR`，让 P 轴重新学习重力补偿。
- 固件升级后先空载或低电流做 10° 小角度测试，不要直接执行整圈或高速跟踪。
- 电机或编码器插头互换后必须重新确认 P/Y 映射和旋转方向。
- 烧录后校验 Flash；测试时保证机构无障碍，并保留独立断电手段。
- 现场命令见 [命令速查表](uart_command_table.md)，主控接线见 [板间控制信号](g431_board_control_signals.md)。
