# EdgefocusBand 手环端技术文档

版本日期：2026-07-08  
适用工程：`stm32/STM32Band_test/`  
硬件平台：STM32G030C8T6 + E104-BT52 蓝牙模块

## 1. 项目概述

EdgefocusBand 是配套主设备使用的 BLE 提醒手环。主设备通过 BLE GATT 向手环写入提醒、倒计时和文本消息；手环侧完成蓝牙连接维护、OLED 状态显示、振动提醒、电池电量显示、按键交互和充电休眠控制。

手环在系统中作为 BLE 外设工作，主设备作为 BLE 主机连接手环。当前固件以 `STM32Band_test` 作为主工程和可烧录工程， reusable 驱动模块同步保存在 `stm32/Drivers/`，便于后续复用到正式产品工程。

## 2. 系统目标

- 通过 BLE 接收主设备发送的提醒信号。
- 支持低延迟振动反馈和 OLED 临时提示。
- 支持倒计时显示，倒计时期间仍显示蓝牙状态。
- 主页面显示设备名、蓝牙连接/广播状态、电池电量。
- 外部电源接入时进入充电休眠，避免挂靠主设备充电时误工作。
- BLE 断开后保持广播，等待主设备重连。
- 兼容旧版主机的 1 字节写入策略，避免因协议版本差异导致完全无响应。

## 3. 硬件组成

| 模块 | 器件/接口 | MCU 引脚 | 说明 |
|---|---|---:|---|
| 主控 | STM32G030C8T6 | - | 手环固件主控 |
| 蓝牙 | E104-BT52 | PA9/PA10 | USART1，默认 115200，8N1 |
| 蓝牙唤醒 | E104-BT52 WKP | PB2 | 下降沿唤醒模块 |
| 蓝牙复位 | E104-BT52 RST | PB10 | 默认高电平 |
| 蓝牙连接状态 | E104-BT52 LINK | PB0 | 读取连接状态 |
| OLED | SSD1306 0.96 寸 | PB6/PB7 | I2C1，地址 0x3C，400 kHz |
| 振动马达 | MOSFET + 马达 | PA6 | TIM16_CH1 PWM，约 5 kHz |
| 电池检测 | 分压输入 | PA4 | ADC1_IN4 |
| 充电状态 | BQ24074 CHG | PB1 | 低电平表示正在充电 |
| 外部电源有效 | BQ24074 PGOOD | PB11 | 低电平表示外部电源有效 |
| 按键 | 外部上拉按键 | PB12 | 按下为低电平 |

## 4. 固件架构

当前固件采用分层模块组织，主循环负责调度，底层模块只封装单一硬件或协议职责。

| 层级 | 主要文件 | 职责 |
|---|---|---|
| 应用层 | `Core/Src/test_ble.c` | 主页面、倒计时、BLE 回调、充电休眠、按键动作 |
| BLE 业务层 | `driver/ble_band.c` | BLE 状态维护、E104 配置、UART 数据接收、协议分发 |
| BLE 模块驱动 | `driver/e104_bt52.c` | AT 指令、唤醒、休眠、复位、UART 收发 |
| 协议解析 | `driver/ble_protocol.c` | Alert/TimeSync/Text/legacy 帧解析 |
| 显示驱动 | `driver/ssd1306.c` | OLED 初始化、ASCII/中文短语、倒计时显示 |
| 马达驱动 | `Core/Src/motor.c` 和 `driver/motor.c` | TIM16 PWM、最小脉冲保护 |
| 电源/电池 | `Core/Src/power.c`、`Core/Src/battery.c` | PGOOD/CHG 读取，电池电压和百分比计算 |
| 按键 | `Core/Src/button.c` | 外部上拉按键读取 |

### 4.1 主循环调度

主循环不使用 RTOS，采用轮询加时间片：

| 任务 | 周期/触发 | 行为 |
|---|---:|---|
| BLE 接收轮询 | 100 ms | 更新连接状态，读取主机写入数据 |
| 倒计时刷新 | 1 s 计算 | 每秒扣减并刷新 OLED |
| 电池检测 | 30 s | 更新缓存电压和百分比 |
| 充电状态检查 | 500 ms | 检测外部电源变化 |
| 外部电源去抖 | 1000 ms | 避免插拔电源瞬态误判 |
| 按键去抖 | 30 ms | 单击亮/熄屏，长按手动 BLE setup |

## 5. BLE 通信设计

### 5.1 GATT 约定

手环作为 BLE 外设广播，主设备连接后向指定特征写入控制帧。

| 项目 | UUID |
|---|---|
| Service | `0x180C` |
| Characteristic | `0x2A56` |
| 方向 | Host -> Band 写入 |
| 设备广播名 | `EdgefocusBand` |

手机 BLE 调试工具连接后可看到自定义服务 `0x0C18`。这是调试工具显示字节序的结果，对应项目约定的 `0x180C`。

### 5.2 E104-BT52 初始化

E104-BT52 模块默认串口参数为 115200、8N1。固件在开机时强制恢复 UART 默认参数，然后唤醒模块并进入 AT 配置流程。

当前配置流程：

1. 唤醒模块。
2. 若已连接，发送 `+++` 进入 AT 模式。
3. 发送 `AT` 验证通信。
4. 设置从机角色：`AT+ROLE=0`。
5. 开启广播：`AT+ADV=1`。
6. 设置透传/数据模式：`AT+TRANMD=1`。
7. 配置睡眠行为：`AT+ONSLEEP=0`。
8. 设置广播名：`AT+NAME=EdgefocusBand`。
9. 设置服务 UUID：`AT+UUIDSVR=` + 原始字节 `0C 18`。
10. 设置特征 UUID：`AT+UUIDMAST=` + 原始字节 `56 2A`。
11. `AT+RESET` 重启模块并重新唤醒。

说明：E104-BT52 的 AT 指令不需要追加 `\r` 或 `\n`。16 位 UUID 在该模块命令中使用原始字节写入，因此 `0x180C` 实际写入 `0C 18`，`0x2A56` 实际写入 `56 2A`。

### 5.3 连接状态维护

固件通过 E104-BT52 的 LINK 引脚判断当前蓝牙状态：

- LINK 有效：显示已连接。
- LINK 无效且模块已配置：显示广播中。
- 未配置或异常：显示离线/错误。

连接断开后，模块保持广播状态，等待主设备侧的重连机制重新连接。

## 6. BLE 信号协议

所有主设备写入均为二进制数据，首字节为类型。

```text
Byte 0: type
Byte 1-N: payload
```

| Type | 名称 | Payload | 手环行为 |
|---:|---|---|---|
| `0x01` | Alert | pattern, optional level | 振动并显示提醒 |
| `0x02` | TimeSync | minutes 高字节, minutes 低字节 | 启动/关闭倒计时 |
| `0x03` | Text | UTF-8 文本 | OLED 临时显示文本 |

### 6.1 Alert

格式：

```text
01 <pattern> [level]
```

| pattern | 含义 | 当前振动策略 |
|---:|---|---|
| `0x00` | 无提醒 | 不振动 |
| `0x01` | 慢速三连 | 3 次振动，间隔约 500 ms |
| `0x02` | 长振 | 单次长振 |
| `0x03` | 快速三连 | 3 次振动，间隔约 100 ms |

`level` 省略时默认为 1。当前 OLED 文案按等级区分：

| level | OLED 提醒 |
|---:|---|
| 1 | 轻提醒 |
| 2 | 注意 |
| 3 | 专注提醒 |
| 4 及以上 | 休息提醒 |

### 6.2 TimeSync

格式：

```text
02 <minutes_hi> <minutes_lo>
```

分钟数采用大端序：

```c
minutes = (minutes_hi << 8) | minutes_lo;
```

`minutes = 0` 时退出倒计时页面并回到主页面。倒计时运行时 OLED 继续显示蓝牙状态，并在倒计时到 0 后自动退出到主页面。

### 6.3 Text

格式：

```text
03 <utf8_text...>
```

手环取前 21 字节用于 OLED 临时显示，显示约 1.5 秒后回到倒计时页或主页面。

### 6.4 Legacy/未知帧兼容

为了兼容旧版主设备和调试工具误写入，当前策略为：

- 空写入：忽略。
- 1 字节写入：按 legacy Alert 处理。
- 非法类型或 malformed 帧：按 legacy Alert 处理。
- legacy Alert：只振动一次，不显示 OLED 提醒。

legacy 振动当前为 500 ms，避免短脉冲因马达启动时间不足而无体感。

## 7. OLED 交互

### 7.1 开机与配置

开机且未检测到外部电源时，OLED 显示“正在与主机打通连接”动画。配置成功后进入主页面；若配置失败，则显示具体 AT 指令或错误回复，便于现场排障。

### 7.2 主页面

主页面包含：

- 设备名：`EdgefocusBand`
- 蓝牙状态：已连接/广播中/离线
- 电池电压和百分比

### 7.3 倒计时页面

倒计时页面包含：

- 剩余时间
- 蓝牙连接状态
- 电池信息由主页面缓存周期更新

倒计时期间收到 Alert，会临时显示提醒级别和文案，随后回到倒计时页面继续计时。

### 7.4 按键交互

| 操作 | 行为 |
|---|---|
| 单击 | OLED 熄屏/亮屏切换 |
| 长按约 2 秒 | 手动触发 BLE setup |

长按触发用于调试和现场恢复：当蓝牙模块配置异常或主机侧调试后 UUID/广播名需要重写时，可不重启 MCU，直接重新执行 BLE 配置流程。

## 8. 振动马达设计

马达由 PA6 的 TIM16_CH1 PWM 驱动，PWM 频率约 5 kHz，当前振动时使用 100% 占空比。

实现上的保护策略：

- `motor_init()` 自包含配置 GPIO AF 和 TIM16，不依赖 CubeMX 初始化顺序。
- 避免重复调用 `HAL_TIM_PWM_Start()`，使用寄存器方式使能输出，规避 HAL 状态机重复启动问题。
- 任意非零振动时长若小于 300 ms，会自动抬升到 300 ms。
- Alert legacy 模式使用 500 ms 单次振动，确保测试工具写入单字节时能被感知。

## 9. 电源与充电策略

手环通过 BQ24074 的 PGOOD 判断外部电源是否有效。固件以“外部电源有效”作为整机休眠条件，而不是只看 CHG 充电状态。

外部电源有效时：

1. 取消当前倒计时。
2. 关闭马达输出。
3. OLED 显示充电/休眠提示。
4. 关闭 OLED 显示。
5. 使 E104-BT52 进入睡眠，停止正常 BLE 工作。

外部电源移除后：

1. 打开 OLED。
2. 唤醒 E104-BT52。
3. 若 BLE 尚未配置，则重新执行 setup。
4. 刷新电池缓存并回到主页面。

PGOOD 变化采用 1000 ms 去抖，避免插拔电源瞬态导致重复 sleep/wakeup 或误触发 Alert。

## 10. 电池检测

电池电压经分压后进入 ADC1_IN4。当前计算参数：

```text
分压系数：1470 / 470
ADC 参考电压：2958 mV
满电阈值：4200 mV
低电阈值：3300 mV
```

电量百分比采用 3300 mV 到 4200 mV 线性映射。主循环每 30 秒刷新一次缓存，减少 ADC 频繁采样对主循环和显示刷新的影响。

## 11. 可靠性设计

- BLE AT 配置逐步检查 `+OK`，失败时 OLED 显示失败命令和回复内容。
- UART 接收会清理 ORE/FE/NE/PE 等错误标志。
- E104-BT52 配置前强制使用 115200、8N1，避免历史调试改动导致 UART 参数不一致。
- BLE 状态打印文本如 `STA:` 会被识别并过滤，不进入业务协议解析。
- 未知 BLE 写入不会破坏状态机，只触发无显示的兼容振动。
- 充电休眠期间跳过 BLE 接收和按键业务，降低误触发概率。
- 断连后保持广播，交由主设备重连。

## 14. 与主设备约定

主设备需要保证：

- 扫描并连接广播名 `EdgefocusBand`。
- 连接后查找 Service `0x180C` 和 Characteristic `0x2A56`。
- 写入数据使用二进制帧，不追加文本格式的分隔符。
- TimeSync 分钟数使用大端序。
- 对手环断连进行自动重连；手环侧断开后会保持广播等待重连。
