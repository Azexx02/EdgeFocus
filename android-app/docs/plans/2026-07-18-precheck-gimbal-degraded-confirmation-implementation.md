# PRECHECK 云台故障降级确认实施计划

1. 在 `PrecheckConfirmationPolicy` 中增加有序云台确认分类，以及确认、手动控制和跳过自动调整的独立资格函数。
2. 让 `PrecheckController` 基于点击后的权威状态执行分类；降级、无云台和已确认位置直接发送 `skip_precheck`，正常搜索仍拒绝。
3. 让位置确认失败后的单次校准识别“命令期间云台转为降级”，继续走固定机位旁路。
4. 首页和控制面板页统一使用策略：降级只启用确认按钮，禁用方向控制与跳过自动调整，并显示固定机位提示。
5. 补充分类矛盾字段、不可用对象、降级旁路、正常搜索保护和准备状态门禁测试。
6. 运行目标单测、完整 Debug 单测和 APK 构建；如设备与故障场景可用则覆盖安装并读取日志验证。若主机拒绝降级 `skip_precheck`，停止并报告，不修改主机。
