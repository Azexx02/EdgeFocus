硬件设计优势
本项目采用 STM32MP257 核心板加自研底板的分层硬件架构。核心计算单元与业务外设分离，既降低了高速 DDR、PMIC 等复杂部分的设计风险，又保留了底板针对应用场景定制的能力，适合学生嵌入式设计大赛中展示“可落地、可迭代、可维护”的工程设计思路。
高性能 MPU 平台，具备 AI 与多媒体扩展空间
系统核心基于 STM32MP257，具备 Linux 运行能力，并预留了 NPU/GPU、多媒体、USB、MIPI DSI、I2S/I2C/SPI 等资源。相比普通 MCU 方案，本设计可以承载更复杂的应用，例如图像采集、姿态识别、本地 AI 推理、无线通信和多任务服务，更适合面向智能终端类作品。
核心板 + 自研底板结构，兼顾可靠性与定制化
核心板承担处理器、内存、电源基础部分，自研底板负责外设连接和应用硬件集成。这种结构的优势是：
降低高速 PCB 设计难度，提高硬件成功率；
底板可根据比赛项目快速修改；
后续可以复用同一核心板开发不同应用；
调试时能区分核心系统问题和底板外设问题。
这体现了比较成熟的嵌入式产品化设计思路。
无线通信链路集成度高
底板集成 RTL8723DU Wi-Fi/蓝牙一体模块，通过 USB Hub 接入主控。该设计让系统具备无线联网、SSH 调试、蓝牙通信和后续移动端交互能力。相比依赖有线网口或串口调试，Wi-Fi/蓝牙方案更贴近实际智能设备使用场景，也减少了终端部署时对线缆的依赖。
USB Hub 扩展结构提升外设接入能力
自研底板使用 CH334R USB Hub，将一路 USB Host 扩展到无线模块、USB 摄像头以及外部 USB 接口。这样可以在有限的主控接口资源下同时支持：
板载 Wi-Fi/蓝牙；
USB 摄像头；
外部 USB 设备；
后续调试或功能扩展。
该设计增强了系统扩展性，也方便比赛阶段快速接入不同传感器或外设。
面向人机交互预留显示与触摸接口
硬件预留 MIPI DSI 显示接口、SPI/LCD 相关接口以及 I2C 触摸信号，为本地人机交互提供基础。虽然具体屏幕适配仍需要结合屏幕驱动和硬件实测继续完善，但从硬件设计角度看，底板已经考虑了显示、触摸、背光、复位等完整链路，不是单纯的无屏计算板。
音频链路采用数字音频方案，结构简洁
底板设计了 ICS-43434 数字麦克风和 MAX98357A 数字功放，使用 I2S/SAI 数字音频链路。该方案相比传统模拟音频链路更简洁，抗干扰能力更好，适合语音采集、提示音播放、人机交互等应用场景。数字麦克风和数字功放的组合也便于后续做语音识别、提醒、报警等功能扩展。
预留运动控制能力
底板包含 STM32G431 外部 MCU 和 STSPIN830 电机驱动相关硬件，为后续执行机构、运动控制或低实时性/高实时性任务分工提供基础。Linux 主控可以负责 AI、通信和上层逻辑，外部 MCU 可以负责实时控制，这种异构分工比单一处理器方案更适合复杂嵌入式系统。
接口资源覆盖完整，适合综合型嵌入式作品
底板综合考虑了无线通信、USB 摄像头、显示触摸、音频输入输出、TF 卡、RTC 电池、电机驱动、Type-C 等模块。它不是单一功能验证板，而是面向完整智能终端的硬件平台，便于在比赛中展示系统集成能力。
